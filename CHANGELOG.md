# Changelog

## 1.1.0
- **Gapless playback** — the next track is opened in advance and joined sample-exactly (default on).
- **Crossfade** — 0–12 s equal-power crossfade between tracks (default off).
- **Radio sound filter** — *Even volume* (K-weighted loudness leveling, gated, ±12 dB, selectable target) and *Clean sound* (40 Hz high-pass, hiss expander, peak limiter) for radio; optional for local files.
- All audio is now normalised to 48 kHz stereo per track so tracks of different formats can be joined.
- 16 new automated tests (81 total).
